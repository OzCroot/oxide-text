# Commands and shortcuts

"Ctrl" means **Cmd** on macOS. Commands without a shortcut are still available from the
menus and the Command Palette (Ctrl+Shift+P).

## File

| Command | Shortcut |
| --- | --- |
| New | Ctrl+N |
| Open… | Ctrl+O |
| Open Folder… | Ctrl+Shift+O |
| Save | Ctrl+S |
| Save As… | Ctrl+Shift+S |
| Save All | — |
| Close Tab | Ctrl+W |
| Export as HTML… | Ctrl+Shift+E |
| Quit | Ctrl+Q |

### Notes on choices

- Ctrl+Shift+N, Ctrl+Shift+T and Ctrl+Shift+Q are used for lists/quotes here; some other
  editors use them for "new window", "reopen closed tab" and "quit". Worth confirming.
- Shortcuts with Shift are checked before the same shortcut without Shift, so
  Ctrl+Shift+P never also triggers Ctrl+P.
