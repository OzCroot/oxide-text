## Overview

## Adding New Content Types

<!-- SCAFFOLD: Describe the steps for adding a new content type -->

1. Define the content type in the CMS admin
2. Add properties (text, media, structured content, and so on)
3. Create the corresponding template/view
4. If the project uses components or blocks, create the component partial
