# Example: Umbraco platform overlay

This directory is a reference shape for `docs/engineering/platform/<platform-name>/`,
not live documentation. It shows the files a CMS-backed project's platform
overlay holds, and the level of detail each one covers.

Copy this directory to `docs/engineering/platform/<platform-name>/` when
the project has a CMS or another platform-bound layer (see
`SCAFFOLD-README.md`'s Milestone 5). Adapt each file to the real platform,
or delete it if the platform has no equivalent. Rename a file when the
platform uses a different term — for example, rename `block-grid.md` to
match a page-builder's own vocabulary.

`SCAFFOLD-README.md`'s Milestone 7 deletes this whole `examples/`
directory once the knowledge base is complete. It is a starting shape for
the scaffolding pass, not a permanent part of the finished project.
