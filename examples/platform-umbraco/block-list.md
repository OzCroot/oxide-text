2. Create the template partial
3. Create the frontend component (if interactive)

## When to Use

- Sequential content (FAQ lists, feature lists, testimonials)
- Content where order matters but layout is linear
- Simpler content structures that do not need grid positioning

Use [Grid Editor](./block-grid.md) when the page needs layout control (columns, areas).
