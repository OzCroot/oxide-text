# Project Overview

> **What this file is for:** a bounded summary of the goals of this project
> — why it exists, not how the team builds it. For the tech stack and the
> architecture, see [../engineering/architecture.md](../engineering/architecture.md).
> The full design is in [../../plan/OXIDE-TEXT-PLAN.md](../../plan/OXIDE-TEXT-PLAN.md).
> Keep this file to the client in one line, then at most 3 sentences.

**Client:** None — oxide-text is an open source project.

**Summary:** oxide-text is a light, open source text editor for Markdown documents, with many tabs in named groups. Code styling is off in the base install. Optional language packs add syntax highlighting and formatting for each language. The default shortcuts follow VS Code and Sublime Text, and the user can change all of them.
